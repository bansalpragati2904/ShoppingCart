# Shopping Cart and Billing Management System

## About the Project
A Java-based Shopping Cart and Billing Management System developed using Java, JDBC, and MySQL.

The project allows users to view and search products, manage cart items, generate bills, apply discounts, place orders, and view order history.

## Features
- View all available products
- Search products by ID
- Add products to cart
- Update product quantities
- Remove products from cart
- Display cart details and subtotal
- Generate bills with automatic discounts
- Place orders and store order details
- View previous order history
- Update product prices

## Technologies Used
- Java
- JDBC
- MySQL
- IntelliJ IDEA

## Project Structure
- `db` – Database connection
- `model` – Project data classes
- `dao` – Database operations
- `service` – Shopping cart and billing logic
- `Main.java` – Main application

## Database Setup
1. Open MySQL.
2. Run the SQL commands provided in `database.sql`.
3. Configure your MySQL username and password in the database connection settings.
4. Add MySQL Connector/J to the project.

## How to Run
1. Open the project in IntelliJ IDEA.
2. Make sure MySQL Server is running.
3. Configure the database connection.
4. Run `Main.java`.
